## 7. Оставшиеся риски

- Старые планы (`intakeV < 5`): «выполнено», не следующее из ответов, помечается ручной отметкой эвристически — если пользователь когда-то получил такой статус автоматически, он останется как «отмечен вами».
- Application Assistant выбирает план по `updatedAt`; при двух планах одного штата с разной классификацией статус подачи уйдёт в более свежий.
- Owner-builder ограничен классом B по двум страницам CSLB; если у CSLB есть иные случаи, правило потребует правки `ownerBuilderClasses`.
- Arizona: страницы ROC по-прежнему недоступны (403) — кнопки «открыть заявление» для AZ нет (`applyPages: null`), правила AZ не перепроверялись в этом раунде.
- Путь с реальной сессией Supabase проверен только фальшивым клиентом; форма запроса (`upsert` c полем `metadata`) соответствует схеме `license-roadmaps.sql`, но на живой базе не прогонялась.
- Ручной статус, отличный от «Выполнено» (выпадающий список на карточке), после `3cb2136` тоже помечается `manual` и сохраняется; для планов, сохранённых ДО этого коммита, такие статусы (не «Выполнено») при первой загрузке будут пересчитаны из ответов.
