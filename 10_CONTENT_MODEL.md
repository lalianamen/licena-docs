## Форматы данных

**EN-банк** — `js/questions/<course>.js`:
`window.COURSE_REGISTRY["<course>"] = [ … ]`, по одному объекту на строку:
`{"id":1,"sec":"…","block":1,"q":"…","opts":[4 строки],"correct":0–3,"re":"…"}`
(`bank-playbook.md` §7; живой пример — `js/questions/epa-608.js`).
`id` — целое, уникален на весь курс, последовательный, не переиспользуется
после удаления.

**Переводы (RU/ES)** — оверлеи `<course>.ru.js` / `<course>.es.js`
(`window.COURSE_LANG`, double-guard): элементы `{id, q, opts, re}` — БЕЗ
`sec`, `block`, `correct`; ключ живёт только в EN; оверлей паруется с базой по
`id`, опции — по индексу внутри элемента. Переупорядочивать `opts` запрещено —
реордер молча ломает ключи (`bank-playbook.md` §6). EN+RU+ES — одним
коммитом. В плеере тот же контракт применяется к строкам из БД
(`js/app-course.js:48–56`, комментарий).

**Гайды** — `js/guides/<id>.js`: `COURSE_GUIDE[id] = {en:[{t,h}], es:[…],
ru:[…]}` (шапки файлов). **Сэмплы** для SEO-страниц — `js/samples/<id>.js`:
отдельные публичные наборы, «Original wording (NOT copied from the paid bank
or any real exam)» (шапка `js/samples/c10-exam.js`); `correct` только в
`en[]`. Исторический образец схемы — `data/questions.example.json`.

## SOP генерации банков (`docs/content/bank-playbook.md`, 199 строк, обязателен)

Структура документа (§1–§10):

1. **Формы** — таблица выше; блоки = карта покрытия доменов реального
   экзамена, `sec` = 4–8 тем внутри блока.
2. **Blueprint до первого вопроса**: официальный outline экзамена (CSLB study
   guide / 40 CFR 82 / 29 CFR 1926) → 5 блоков → sec-лист → целевые
   количества → точные главы источников; проценты трекают официальный
   outline.
3. **Источники**: только открытые официальные/первичные; реальные экзамены и
   коммерческие банки запрещены (IP); формулировки с нуля; «no memory
   numbers» — каждое число перепроверяется в источнике в момент написания;
   недоступный источник = вопрос не пишется.
4. **Правила вопроса** (10 пунктов): один защитимый ключ; пиновый стем;
   дистракторы — реальные заблуждения; без giveaway'ев (чекер флагает ключ
   длиннее 1.6× среднего); распределение A–D 20–30% при написании (реордер
   после переводов запрещён); каждая аббревиатура раскрывается в самом
   вопросе (Terms-хвост в `re`: EN `Terms:` / RU `Термины:` / ES
   `Términos:`); `re` объясняет ПОЧЕМУ и называет раздел кода; негативные
   стемы ≤ ~5 на блок с капитализированным NOT; опции ≤ ~90 символов.
   В §4 — worked examples GOOD/BAD.
5. **Батч-цикл**: 20–25 вопросов на батч по одной ячейке blueprint; fact
   ledger `id | sec | факт | источник | буква ключа`, перечитывается перед
   каждым батчем (анти-повтор); после каждого батча `node --check` +
   `scripts/check-banks.js`; финальный проход: чекер чисто → семантическая
   зачистка → 100% числовых ключей + 10% выборка переверифицированы.
6. **Переводы**: правила оверлеев (см. «Форматы данных»); английский термин
   рядом с переводом при первом употреблении; числа/циты идентичны EN.
7. **Файловая механика** (формат файлов, id, escaping; для нового курса — ещё
   каталог, `EXAM_FORMATS`, гайд, запись в `bank-updates.js`).
8. **Ship-гейты** (9 чекбоксов): verify.js чисто; 0 ошибок чекера; A–D в
   20–30%; переверификация ключей; standalone-вопросы; семантическая
   зачистка; выравнивание EN/RU/ES; рендер-проверка блоков; отчёт с
   blueprint и источниками. «Anything UNVERIFIED was cut, not shipped».
9. **Модель-независимость**: на слабой модели батчи 10–15 и чаще чекер;
   планка качества не снижается — снижается объём.
10. **Распределение моделей** (owner decision 2026-08-04): генерация — топ-
    модель сессии (Fable); переводы — Opus; верификация — топ-модель в
    основном цикле.

### Факт, меняющий картину: в Луизиане нет экзамена по сантехнике

Классификация 7 (Plumbing) помечена в официальном списке LSLBC как
**`Credential`**, а не `Trade Exam`. Формулировка LSLBC: механический
подрядчик, выполняющий сантехнические работы дороже $10 000, обязан иметь
лицензию **master plumber от State Plumbing Board of Louisiana** — отдельного
органа. В каталоге из 55 экзаменов PSI `lacon` сантехнического экзамена нет.

Практическое следствие: сантехническое содержание Луизианы живёт в экзамене
**Mechanical Work** — 55 из 100 его вопросов приходятся на сантехнические
области (Cleanouts, Plumbing Fixtures, Water Heaters, Water Supply, DWV,
Backflow, Traps and Interceptors, Developed length, Isometric Analysis,
General Plumbing Regulations, Joints and Connections, Fire Sprinklers).

### Доступность источников — проверено поимённо 2026-09-22

Правило CLAUDE.md «нет открытого официального источника — вопрос не пишется»
делает доступность источников условием существования банка. Проверка показала
чёткую границу: **модельные коды ICC читаются свободно, стандарты NFPA и ACCA —
нет.**

| Источник | Где читается | Статус |
|---|---|---|
| IPC 2018 | `up.codes/viewer/texas/ipc-2018` (Adopts Without Amendments) | доступен |
| IMC 2018 | `up.codes/viewer/wyoming/imc-2018` (без поправок) | доступен |
| IFGC 2018 | `up.codes/viewer/texas/ifgc-2018` (без поправок) | доступен |
| IMC 2021 / IFGC 2021 | `up.codes/viewer/wyoming/…` (без поправок) | доступны |
| IRC 2018 | `up.codes/viewer/texas/irc-2018` (без поправок) | доступен |
| IBC 2018 | `up.codes/viewer/wyoming/ibc-2018` (без поправок) | доступен (уже использован в `la-building`) |
| 29 CFR 1926 | `osha.gov` | доступен (public domain, 17 U.S.C. § 105) |
| **NFPA 70 (NEC) 2023** | up.codes отдаёт только оглавление | **недоступен** |
| NFPA 13 (2002), NFPA 58 (2011) | то же | недоступны |
| ACCA Manual J / N / D | то же | недоступны |
| SMACNA, Modern Refrigeration, Ugly's, Pipefitters Handbook | открытого текста нет | недоступны |

Луизиана принимает коды ICC с поправками, поэтому для авторства берётся
модельный текст из штата, помеченного «Adopts Without Amendments» — именно та
редакция, которую называет PSI. Тот же приём уже применён в `la-building`
(IBC 2018 через Вайоминг).

### Зафиксированные пробелы (следствие недоступных источников)

- `la-mechanical`, ячейка **Fire Sprinkler Basics** (20 из 500): PSI указывает
  NFPA 13 (2002). Пишется только то, что есть в IBC 2018 §903 и IRC 2018
  §P2904 — «где спринклеры требуются» и основы жилых систем. Детальные правила
  NFPA 13 (шаг спринклеров, площадь покрытия, гидравлика) в банк не попадают.
- `la-mechanical` и `la-hvac`, ячейки **Load Calculation** (25 и 20 из 500):
  PSI указывает ACCA Manual N / Manual J. Пишется расчёт по данным самого
  кода — таблица расхода наружного воздуха IMC §403.3, баланс притока и
  вытяжки, подбор сечения по расходу и скорости. Методика Manual J (расчёт
  теплопоступлений и теплопотерь по ограждающим конструкциям) не попадает.
- `la-hvac`, **блок 2** (электрика, 100 из 500): NEC в список источников этого
  экзамена не входит, а Ugly's недоступен. Блок построен на электрических
  требованиях самого IMC и на 29 CFR 1926 Subpart K. Табличные данные NEC
  (сечения, допустимые токи) не попадают.
