## Кабинет (`app.html`, `js/app-cabinet.js`, `js/i18n-app.js`)

- **Селектор штата** в шапке кабинета: California / Arizona; курс, добавленный
  в одном штате, остаётся у пользователя и во втором — это один курс
  (`js/catalog/az.js`, комментарий; системный промпт
  `supabase/functions/assistant/index.ts`).
- **My courses**: активные курсы; новым аккаунтам автоматически добавляются
  `contractor-business` (гайд A–Z) и `epa-608`
  (`supabase/sql/backfill-business-guide.sql`, комментарий).
- **Каталог**: категории отфильтрованы `LAUNCH_CATEGORIES=["construction"]`
  (`js/app-cabinet.js:72`); курс с флагом `test:true` виден только тестерам
  (`js/app-cabinet.js:81–83`).
- **Path wizard**: подбор лицензии → список нужных экзаменов, фильтруется по
  выбранному штату (`js/paths.js`; `js/app-cabinet.js:450–451`).
- **Добавление курса** — три ветки (`js/app-cabinet.js:982–994, 1155–1173`):
  - бесплатный → активация без оплаты (`activateBtn`);
  - платный, триал не использован → кнопка «3-day trial» (RPC `start_trial`,
    без карты);
  - платный, триал использован (строка в `course_trials` переживает удаление
    курса) → кнопка «Subscribe» (`js/app-cabinet.js:5–8, 662`).
- **Оплата**: Stripe Checkout ($20/мес за курс), уход на страницу Stripe и
  возврат на `app.html?checkout=success|cancel`; при success кабинет
  опрашивает появление строки доступа, записанной вебхуком
  (`js/app-cabinet.js:688–730`, `handleCheckoutReturn`).
- **Пауза подписки**: истёкший триал/подписка → курс становится `inactive`,
  карточка показывает Subscribe, весь прогресс сохраняется
  (`supabase/sql/trial-3day.sql`, комментарий; cron `expire-subscriptions`).
- **Управление подпиской**: Stripe Customer Portal — отмена в любой момент,
  смена карты, инвойсы (`js/app-cabinet.js:708–719`).
- **Тестер-баннер**: «🎁 free access extended until …» по `expires_at`
  без email в клиентском коде (`js/app-cabinet.js:651–662`;
  `supabase/sql/extend-tester-trials-oct31.sql`, комментарий).
- **Журнал обновлений банков** на панели My courses: до 6 записей — дата,
  банк, что изменилось, источники, год данных (`js/bank-updates.js`,
  `js/bank-updates-render.js`).
- **Слот официальных ресурсов** (`js/resources-render.js`).
- **Аккаунт**: имя, email, язык обучения, «Leave a review» (отзыв уходит в
  статус pending на модерацию — `supabase/reviews.sql`); список своих
  устройств (`js/app-cabinet.js:920`).
- **Онбординг-туры** (coach marks): по одному на зону — My courses, Catalog,
  Account, плеер; каждый показывается один раз (localStorage), без внешних
  ресурсов (`js/onboarding.js`, шапка).
- **Анти-шеринг UX**: новое устройство при входе → диалог «Add this device?»
  (dry-run RPC `'add'`); лимит 5 и замена недоступна → нейтральный экран
  «device limit reached» (`'blocked'`); сбой бэкенда → вход разрешён
  (fail-open) (`js/devices.js`; `README.md` осн. репо, раздел Anti-sharing).
- **Чат саппорта**: ответы с обоснованием через web search на сервере; приём
  запросов на курсы/языки и жалоб (пишутся в `support_tickets`); загрузка
  скриншотов (приватный бакет, signed URL; `js/support.js`;
  `supabase/support_uploads_storage.sql`).

## Плеер курса (`course.html`, `js/app-course.js`)

- **Режимы отображения вопроса** (`studyLang`): `en`, `en+ru` (двуязычный
  side-by-side), `ru`, `es`; выбор хранится per-course
  (`js/app-course.js:3,9,250–331`); staged-язык `hy` виден только тестерам
  (`js/catalog/ca.js`, `testLangs`).
- **Блоки**: карточки блоков для банков с полем `block`
  (`buildBlockCards`/`activeBlock`); внутри блока — навигация по секциям
  (`sec`; `js/course-blocks.js`; `CLAUDE.md` осн. репо).
- **Перемешивание**: порядок вопросов перемешан и **сохраняется** (ids) на
  курс/блок/секцию; повторное открытие продолжает с первого неотвеченного;
  новый шафл — только при явном рестарте (`js/app-course.js:642–681`).
  Порядок вариантов ответа перемешан отдельно, стабилен в рамках захода
  (`js/app-course.js:383–385`).
- **Объяснение** (`re`) к каждому вопросу; для платных банков вопросы
  подгружаются из `bank_questions` (EN + активный язык) с пагинацией
  (`js/app-course.js:48–107,142–170`).
- **Блок «Honest chances»** — сворачиваемый блок в шапке курса
  (`js/honest-chances.js`).
- **Справочная панель** (сайдбар): официальные источники, свежие изменения,
  региональные исключения, ключевые расчёты по курсу (`js/course-ref.js`).
- **Инструменты курса** (retention; итоговый вид — запрос владельца
  2026-08-10 по скриншоту живого плеера): в ЛЕВОМ сайдбаре секция
  «Инструменты» — сворачиваемая, ПО УМОЛЧАНИЮ СВЁРНУТА (в стиле справочной
  панели, `ref-sec`); внутри — обозначение расчёта («Расчёт нагрузки и
  типоразмера + материалы для монтажа») и примечание, что он откроется
  отдельной страницей. Клик открывает страницу `/tools/…` в новой вкладке и
  ставит штамп `lp:tool_gate` (localStorage); страница без свежего штампа
  (15 мин, обновляется при перезагрузках) редиректит на лендинг — напрямую
  отдельной страницей её открыть нельзя. Встроенной карточки/iframe в
  основной колонке больше нет (`?embed=1` удалён). Реестр `COURSE_TOOLS` —
  per-course: калькуляторы добавляются любому банку одной записью
  (`COURSE_TOOLS`/`buildCourseTools` в `js/app-course.js`, `#sideTools` в
  `course.html`; git `main` `abd8804`). С `4234bff` реестр разделён на
  `TOOL_DEFS` (8 калькуляторов) + `COURSE_TOOLS` (списки ключей на курс);
  инструменты назначены 16 курсам; с `6530354` (решение владельца
  2026-08-11) — ТОЛЬКО ПЛАТНЫМ банкам (это retention-ценность подписки):
  `epa-608`, `nicet-fire-alarm`, `nicet-water-based` удалены из реестра.
  Итоговая карта (13 платных курсов): hvac + hvacdesign → `c20-exam`;
  electrical → `c10-exam`, `c7-low-voltage`; plumbing → `c36-plumbing`;
  roofing → `c39-roofing`, B, B-2; concrete → `c8-concrete`,
  `c27-landscaping`, B, B-2; painting → `c33-painting`, B-2;
  solar → `c46-solar`; fire → `c16-fire-sprinkler`; pricing → `cslb-law`.
- **Справочная панель: все секции свёрнуты по умолчанию** (запрос владельца
  2026-08-10; раньше первая — «Официальные источники» — открывалась сама;
  `renderCourseRef` в `js/app-course.js`, git `main` `abd8804`).
- **Курсы-гайды** (type `guide`): статьи EN/ES/RU из `COURSE_GUIDE`
  (`js/guides/*.js`).
- **Режим экзамена** (`js/app-course.js:856–1052`):
  - по умолчанию 120 вопросов, проходной 75 %, 210 минут; доступен для банков
    от 120 вопросов (`EXAM_COUNT`, `EXAM_PASS_PCT`, `EXAM_MINUTES.DEFAULT`,
    `EXAM_MIN_BANK`);
  - спец-форматы (`EXAM_FORMATS`): `epa-608` — 25 вопросов из каждого блока,
    порог 72 % в каждой секции отдельно; `osha-construction` — 20 вопросов,
    70 % на весь тест;
  - модальное окно правил перед стартом строится из реального формата курса
    (`examRuleLines`);
  - активная попытка хранит `qids, startedAt, endsAt, answers, flags,
    submitted` — флажки вопросов, таймер, продолжение попытки после
    перезагрузки (localStorage, `js/app-course.js:883–899`);
  - результат последней попытки сохраняется и показывается
    («Последний экзамен: {pct}% — {verdict}»; `js/i18n-app.js:308`).
- **Доступ**: плеер проверяет строку `user_courses` при открытии курса
  (`js/app-course.js:97,734`); платный неактивный курс показывает пейвол.

## Инструменты `/tools/*` (EN + `es/`, `ru/`) — course-gated

на страницах `/tools/` не подключается (см. `12_SEO.md`).

(21 страница, единая логика `js/trade-calcs.js`, тот же гейт/noindex, вне
sitemap): `electrical-calculator` (VD = 2·K·I·L/CM, NEC гл. 9 табл. 8, цель
